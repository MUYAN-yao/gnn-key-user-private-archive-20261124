# 证据与图形决策

历史协议与配置匹配200预算、160参数、80固定边、60种子预算、20合成条件。九臂包括3个随机池；随机池需先在路径内平均。原Fig4的参数/耦合面板只含Weighted-4k且连接离散类别，因此保留原图但不直接入稿为全方法敏感性证据。

新图契约：Python/matplotlib，Computing单栏119mm，字体接近正文（9pt），PDF/SVG矢量、PNG预览。参数图为四图实例的纵向定量面板，离散(p,h)类别、Degree/PageRank/Weighted三种4k方法，均值与路径SD；不连接类别，不做总体成功率检验。支持图为固定边320→1280的逐路径传播差，条件MC区间，四网络分面；不会相减step与edge逐世界数组。

完整方法及路径统计保留CSV；参数表包含20图×参数组合（默认来自已有resolution）的三方法60行。k20全池和高覆盖必须明示。未执行的外部参数/严格容差×edge联合控制不能由历史结果替代。
