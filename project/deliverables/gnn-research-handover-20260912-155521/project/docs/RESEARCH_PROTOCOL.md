# 研究执行与投稿协议

## 研究问题

在历史传播不完整时，从有向时序互动网络中选择 `K` 个初始用户，使未来扩散覆盖的下置信界最大，并提升种子集的社区覆盖。论文不将“使用 GNN、ACO 或 SIR”本身作为创新，而检验时序边不确定性和跨社区约束是否带来稳定增益。

## 数据准入

每个候选数据集都必须满足下列条件后才可进入主实验：

1. 节点表示用户而非仅表示帖子；
2. 有有向互动边及可解析时间戳；
3. 至少能从互动或级联记录构造传播父子关系；
4. 许可允许研究使用与派生统计发布；
5. 训练、验证、测试时间窗均至少有有效边。

建议优先核验 Higgs Twitter、Digg 和合法公开的 Weibo 级联数据。Twitter15/16 仅可作为谣言传播分类辅助资料，不能作为本研究的用户影响力主基准。

## 三时间切分

对每个数据集按时间排序建立三个滚动切分：`60/20/20`、`65/15/20`、`70/10/20`。任何归一化统计、社区划分、GNN 训练和传播参数估计只能在每个切分的训练窗口完成；测试窗口仅用于最终指标。

每个切分执行五个随机种子。报告均值、标准差和 95% bootstrap 置信区间。若本方法未在两个数据集的多数切分中超过最强基线，不主张方法有效，而转写为可复现基准和失败模式分析。

## 论文结果表

主表至少含：方法、平均覆盖、覆盖标准差、下置信界、社区覆盖、运行时间；附表含 AUC、AP、Brier、ECE。所有数值必须来自版本化 JSON 结果，禁止手工改写。

## 可公开归档

提交前冻结：论文 PDF、代码 commit、`requirements.txt`、数据卡、处理脚本、运行配置、原始 JSON 结果和复现实验命令。发布至允许公开引用的归档平台并记录 DOI/永久链接；真实数据若受限，只公开下载说明、校验和及处理代码。
