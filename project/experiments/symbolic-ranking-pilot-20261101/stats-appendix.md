# 统计附录（预先定义的解释规则）
主要预测目标：PR参考20候选下，最终5种子集合相对独立W1280选择参考的1-Jaccard；越小越稳定。不是效用损失。模型评价按整图等权MSE和MAE。
训练5图、验证2图、留出8图；每图4路径×3预算=12行。这些行共享图、先导特征和参考解，不能当独立网络。ER/BA为开发图族，SBM/WS整族留出；两真实留出图已在历史研究探索，不是确认性证据。
效用差采用同一批10000独立评价世界的逐世界成对差D，SE=sd(D,ddof=1)/sqrt(10000)，区间mean(D)±1.96SE。世界独立性以继承的哈希伪随机构造为前提。区间条件于固定图及选出的集合，只刻画评价模拟噪声；不包含图抽样和选种子算法变异。精确相同种子集合D恒为0，为确定性相等；其他CI跨0条件称尚无法区分，绝不称等效。
所有效用区间是探索性逐比较区间，未做多重校正；不由其产生总体显著性或优越性主张。未安排网络总体p检验：图来自便利样本和少数生成机制，独立图数不足且不代表总体。不用世界数伪造n=10000的网络推断。
模型MSE差的2000次整图重采样区间仅描述固定留出图组成敏感性，随机种子7201；图族相关未被消除，不能视为总体置信区间。主要结论依预声明效果阈值、8图改善数量与3次训练整图重采样结构稳定性，不依p值。
先导前两候选由160先导世界选择，因此该先导gap本身有赢家偏差；它与后续选择/评价独立但不是已知真gap。选择各轮winner margin及其SE也为同批赢家/次佳的描述，不作无偏真值或全流程概率保证。方差始终对共同世界的成对差计算。
最高W和参考W均为1280，独立参考路径4999并非真最优；标签包含参考的有限模拟误差，不能把它当实际部署输入。PR参考检查1e-14与1e-15的残差、最大分数差和候选成员；不保证任意更高精度数学排序，特别是精确/浮点近同分。
