# 创新点调整后的补证据方案

日期：2026-09-15。当前状态：首个 v4 诊断已完成；本文件是后续实验设计，未预注册，未启动正式批次。保留全部已知负结果，不以显著性决定追加运行。

## 1. 当前能写与不能写的贡献

已能写：将概率预测、种子集合选择和搜索阶段成本分别验证；v3 的三十次运行保留完整搜索的有序选点并记录更低局部耗时；v4 单次机制诊断显示加权出度与 GNN 可得到完全相同结果。

尚不能写：学习概率改善选种、GNN 筛选优于简单筛选、风险与社区项带来独立收益、端到端加速、严格在线无未来信息。标题中的“传播概率建模”描述模块用途，不等于已恢复 GNN 的正面创新主张。

## 2. 先完成同预算筛选的正式比较

沿用已提出的三个切分 0.60/0.65/0.70、每个切分新种子 52–61，共 30 块；0.70/48 诊断不并入。主对照为时间衰减加权出度，辅助对照为原方向标准加权 PageRank、均匀随机池；四池均为 120，k=2，时域 4，λ=0.35，η=0.25。概率图每块训练一次后共享，选择/评估世界各 20 且互斥；随机池独立命名空间。形成成员资格后统一字符串 ID 顺序，六位小数比较和精确并列先到规则保持一致。

正式入口需要在单次诊断入口之外另行版本化，补齐当前记录的不足：保存每臂顺序并预先随机化；分别记录候选生成/排序、搜索、独立评估耗时；尽可能将训练、校准与概率推理分开计时，若无法分开必须如实保留合并阶段。禁止把现有合并时间拆成推算的子阶段时间。记录硬件、同步计时、冷/热启动口径和所有源码依赖哈希。

主指标是共同独立评估世界中的 J，差值为 GNN 减对照。主家族为三个切分的 GNN–加权出度对比（3 项 Holm）；辅助家族为 GNN–PageRank/随机（6 项单独 Holm）。每项 n=10，报告配对差、样本 SD、95% 配对均值 t 区间、精确双侧符号翻转 p、Holm p、胜平负和 dz；全零差时 dz 未定义，不写为已证明等效。三个时间前缀不是独立网络，扩散世界不是额外训练重复。

计时只作预先约定的阶段描述，完整成本为“共享前置成本 + 本臂附加成本”；加权出度臂仍使用学习概率，不得把训练成本记成零。不要重复旧完整候选搜索，也不要声称新的种子 52–61 已匹配旧完整搜索。

该比较沿用冻结负样本规则以隔离筛选因素，并明确全期边集合限制。完成后不论结果正负均报告：若同选点同效用，则保留候选缩减观察、撤回学习筛选独特性；若存在差异，则按切分、效应量与校正结果限定表述。

## 3. 再检验概率模型，先解决评价标准

这个问题与筛选实验独立编号，不能直接删除 GNN 后让每个方法按自己的概率模拟得分，再横向比较数值。不同概率图会改变评分尺度；用学习图评所有种子集也可能偏向匹配该模型的方案，不能作为真实传播效益证据。

建议先做可定义的预测对照，再做条件性的选择对照：

1. 新的仅历史信息协议：按时间分组切分；负样本资格只使用拟合截止时可用关系，固定节点全集则仍明确为转导设定。一个历史负例后来成为正例不能被未来记录悄悄排除。该改动创建新版本并重新验证，不改 v1–v4。
2. 比较固定 T0 架构、常数概率基线、简单结构统计模型。常数只从训练标签率估计；结构模型可用历史加权出/入度和边权作逻辑回归，特征与正则化在运行前固定。各模型使用同一训练样本、同一校准窗口和同一外部测试对，不能为不同模型重抽有利的负样本。模型选择不看外部测试。
3. 先以外部边预测的 ROC-AUC、AP、Brier、ECE 比较排序和校准。在平衡抽样下，常数概率接近 0.5 不等于现实传播概率；必须报告采样率，不能把预测门槛当作因果传播校准。统计家族、主指标和运行数在新协议锁定时确定。
4. 若开展选种对照，固定同一结构候选池、预算、目标及优化器，仅改变用于选择的概率图。所有选集须进入同一预先指定的外部评价机制。若缺少独立传播真值，可预先固定多个共同模拟场景作敏感性验证，每个场景内配对比较并全部报告；这仅证明对这些模拟条件的适配，不能证明现实传播收益。

当前 Higgs 活动和 Digg 暴露代理不提供充分的完整因果传播真值。仅靠现有数据可能无法支撑“学习真实传播概率”或“提升实际扩散”的创新点，最终贡献应保留这一边界。

## 4. 论文决策规则

- 筛选无增益但阶段成本降低：以候选缩减的条件性效果—成本分析为主，GNN 排序作为被检验的实现选择。
- 预测对照有支持、选择对照尚未建立：只主张预测上的条件性收益，不把它提升为种子选择收益。
- 概率与筛选均无独立增益：保留方法评估与机制负结果；不能通过更换标题宣称新的算法突破，需重新评估投稿竞争力。
- 若要建立更广泛贡献：在预先固定的更大预算或独立网络上验证；不因本批次不显著就无限扩充种子数量。
