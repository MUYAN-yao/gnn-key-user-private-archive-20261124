# 候选截断评估：开发层冻结协议

日期：2026-09-20；版本 0.1；状态：冻结为开发层，不可用于确认性泛化或投稿主结论。

## 固定问题

在每个已存在的本地输入上，以前 65% 的完整时间戳组构造有向历史图；对边赋
固定 IC 概率 0.05、传播步数 4。在同一组固定选择世界上，以**平均激活人数**
为唯一选择目标，比较全候选贪心与既有候选截断启发式。风险/社区目标不进入
本版本运行。

## 固定开发矩阵

| 项目 | 值 |
| --- | --- |
| 输入 | 本地 `digg/pilot-5000`、`higgs-twitter/pilot-1500`；仅开发用途 |
| 预算 | k = 5, 20 |
| block seeds | 101, 102, 103 |
| 选择世界 | 20；由 `candidate-truncation-development-v0_1`、数据名、seed、索引确定 |
| 独立评价世界 | 1,000；与选择世界分离 |
| 方法 | full；degree/pagerank 的 k、2k、4k、8k、16k 固定池；degree doubling |
| GNN | 不运行：本地没有冻结、可复放且成本可记录的模型/概率输入 |
| 计时 | 串行；记录 common、ranking、decision 和冷启动组件和 |

总计 2 × 2 × 3 × 12 = 144 个方法执行，但每 block 的 full 参考只计算一次。
每个输入在运行时保存 SHA-256；输出拒绝覆盖。

## 不可更改规则

- 不因结果改变 k、世界数、池倍数、排序、概率、方法或种子；变动即另立版本。
- 不以三个随机 seed 当成三个独立网络；开发结果只用于检查效应存在、失败模式
  与计算资源，不能估计网络总体效应或输出 p 值。
- 不隐去任何失败、超时或没有 GNN 的原因；不把 full 同解描述为新方法效果。
- 选择与评价共享每个 block 内的方法世界，但评价世界从不进入候选排序或停止。

## 开发判定

完成后只回答：是否存在跨两个本地输入与两个预算可复现的截断质量—成本差异，
PageRank/degree/doubling 是否呈现不同失败型态，以及全候选金标准是否可负担。
这些结果若不足以形成明确评估发现，结束该论文线；若值得继续，另立确认层并先
解决外部数据准入。
