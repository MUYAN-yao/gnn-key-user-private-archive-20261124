# v7 方法备忘：固定世界下的候选检查

日期：2026-09-19。这是设计候选，尚无网络性能实验。不主张首次提出
分支定界、逐步采样或候选筛选；数学正确性与新颖性分别审查。

## 1. 被保证的对象

给定图、概率表、社区、传播步数h、W个固定选择世界和当前种子集合S。
对候选v，x_i为S并入v后的第i个世界总激活人数，目标为

    J_v = mean(x) - lambda*population_SD(x) + eta*C(S union {v})

lambda非负；主设计lambda=7/20，eta=1/4。标准差分母W。
保证仅针对同一个有限世界目标下的完整贪心序列，不是全局最优、
总体期望最优或真实传播保证。候选排序只影响计算顺序。

## 2. 上界及证明

已评估r个世界，A_r=sum(x_i)，Q_r=sum(x_i^2)，
D_r=Q_r-A_r^2/r（r=0时令D_0=0）。未评估的x_i均不超过B_v。

    U_v(r) = [A_r+(W-r)*B_v]/W - lambda*sqrt(D_r/W) + eta*C

均值不超过第一项。设全部世界均值mu，则

    sum_all (x_i-mu)^2 >= sum_observed (x_i-mu)^2
                           >= min_a sum_observed (x_i-a)^2 = D_r

所以标准差不小于sqrt(D_r/W)，lambda>=0保证U_v(r)>=J_v。
r=W时U等于J。证明不需要世界独立、次模性或目标单调。
不能把观测标准差sqrt(D_r/r)误作全部标准差下界。

B_v取S并入v的有向h跳结构可达节点并集大小，含种子自身。
B_v=n也是合法但较松的上界。不能只取v的可达数；不能把S与v单独模拟
的结果相减当作合法边际界。步数相关随机世界也不影响结构可达上界。

## 3. CHECK_RISK 最小规则

每轮固定S，按指定排序取前min(2k,|V-S|)个未选节点，完整评估W个世界，
产生当前最好节点。其余所有节点都建立合法上界，按上界降序、字符串ID
破同分处理。不能排除的候选按固定世界顺序每批补4个世界；可排除则停止，
否则到W时计算完整得分并更新当前最好节点。所有节点均已评估或被合法
排除后才提交胜者。新增种子后重新计算该S对应的候选目标。

池外节点进入模拟称promotion。算法仍检查所有节点的便宜信息，
不能把完整模拟次数减少描述成完全不访问池外节点。

## 4. 强对照

- FULL：完整扫描、完整世界的规范参考实现。
- GENERIC_BOUND：无初始候选池的普通best-upper-bound-first分支定界。
  同一B和SSE上界，先完整评估最大上界节点形成最好值，再处理其余候选。
- CHECK_MEAN_BOUND：同初始池、调度和缓存，上界不减SSE项，最终目标仍含SD。
- B=n开发消融：检验结构上界的计算是否值得；不扩大正式主矩阵。

普通分支定界若解释全部收益，则初始池/扩展调度的独立贡献未成立。
SSE项无额外收益时，不把风险信息称为已验证的效率来源。

## 5. 独立v7数值协议

旧v6使用NumPy评分再round六位。本设计保留六位得分和字符串ID破同分
的含义，另立可保守计算的v7评分器，不宣称逐字节重放旧浮点结果。

完整向量用整数A,Q和N=W*Q-A*A计算

    J = [A-(7/20)*sqrt(N)]/W + (1/4)*C

数学J半偶舍入到1e-6后，以整数微单位q比较。所有系数用精确有理数。
sqrt(N)用isqrt和十进制缩放得到有理区间，细化到两端舍入一致。
完全平方直接精确求值；非平方N使主目标不落在有理半微单位边界，精化
可终止。lambda=0等有理特例直接精确计算。精度/时间受限时报告未完成，
不能回退成未经证明的浮点比较。所有臂共用此评分器。

部分上界令D=r*Q_r-A_r*A_r。r>0时

    t = isqrt(floor(D*10^(2d)/(r*W)))

t/10^d是sqrt(D/(rW))的下界，代入得到有理U_upper；r=0另设0。
令q_upper=ceil(1e6*U_upper)，仅q_upper<q_incumbent时剪枝。
等号继续评估；r=W直接进入完整精确评分。负数同样使用数学ceil。

当前只完成了数学审查和浮点小向量检查，生产数值实现仍待编写验证。

## 6. 成本、缓存与退化

- h跳可达集合按需构造并计时；每臂冷缓存起跑。拓扑缓存限256 MiB，
  确定性LRU。超限清除缓存不删除候选，不改变正确性。
- 模拟缓存键包含全部输入/配置哈希、规范种子集合及world ID。
  所有臂获得相同合法缓存机会，不共享其他臂算出的full结果。
- 结构上界、排序、检查、数值区间、扩容和回退全部计入决策时间。
- B很大、实际传播很小或接近同分时可能几乎无法剪枝，必须保留这种结果。
- 超时当前最好值不等于已经确认的胜者，必须标为未获证书/未完成。
