# 本轮机制图与文字修改

新增两张图，均在 Microsoft Visio 中通过原生形状绘制，可逐项编辑。

1. 正文图1：重构为连续的计算机制叙事，而不是并列流程卡片。先显示固定传播图上的候选截断边界；再用两条颜色路径区分 $W$ 如何改变全候选参照、容差如何在截断边界交换候选成员；两路最终在配对选择和独立传播效用处汇合。ca-GrQc 的“2/20候选成员交换、W=1280时5/5条路径种子集变化”只作为右下方实测锚点，完整效应量继续由正文的精度图承担。
2. 补充材料图2：按步耦合的时序反例。用三节点链说明，多加一个初始种子会提前其尝试时点，从而改变所用随机数；在特定世界中可由传播3个节点变为2个节点。图注保留“不由此直接否定次模性或固定种子集边际传播规律”的边界。

写作上修改了图注，并使图中术语与方法部分一致。采用计算类顶会常见的“先给一个可见的反直觉风险，再拆分变量的作用位置，最后交给可检验的输出”的顺序，避免把新图写成算法创新或新实验证据。主文现为21页，补充材料仍为11页；期刊模板、字号、行距和版心不变。

风格参考来自 Nature 的 AlphaFold 图1e及 NeurIPS 的 Transformer 图1，借鉴信息流、模块层级、对齐和直接标注的原则，未复制其图像。具体来源及设计依据见 `audit/design_reference_and_evidence.md`。

当前 `.vsdx` 包含2页、179个原生形状，其中59个含可编辑文字；没有嵌入图片。Visio本机直接导出PDF失败，因此采用 Visio原生SVG导出后转矢量PDF的路线。SVG中的样式被显式化、Arial映射为Helvetica，并检查了箭头、字体和版面；PDF不含栅格图。原生Visio文件与导出PNG均保留。

本轮补的是计算过程及其作用路径的解释，不能替代真实传播因果机制实验。未新增效用实验，未改变效应量、统计单位、事后敏感性身份、原始矩阵或已有审计结果。
