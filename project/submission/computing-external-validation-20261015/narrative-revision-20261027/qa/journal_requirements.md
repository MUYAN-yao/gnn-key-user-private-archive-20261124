# Computing格式核对

执行日期：2026-10-27。
官方来源：https://link.springer.com/journal/607/submission-guidelines

- 单栏LaTeX，smallextended；初稿和终稿均不超过25页，不使用压缩排版技巧。
- 摘要150—250词，关键词4—6个。
- 提交summary说明新颖性及评价方式；regular paper附简短cover letter说明期刊匹配。
- 提交可编辑源文件；图表应清晰可读。

本轮沿用原Springer类文件与版心，摘要字数、关键词、页数和编译诊断见revision_checks.json。作者声明照原已确认稿件保持不变。图1保持作者提供的机制图；其字体大小未在本轮调整，不将哈希一致当作对可读性要求的全面认证。
