# 问题驱动的论证修订（2026-10-28）

## 研究问题先于实验清单

原稿在摘要开头指出两个数值选择后，迅速进入各网络的结果，读者不易判断为什么这些比较值得做。本版先说明：全候选参照也是有限采样所得，候选资格又由数值排名确定，因此受限方法相对参照的差值需要辨别其来源。配对选择、分别改变预算与容差、独立传播评估构成回答这个问题的具体途径。这是对已有研究问题与证据的重新组织，没有新增理论、机制或实验。

摘要按“难题—研究途径—有限样本—主要发现—评价意义”重写，英文172词（按保存的检查脚本口径）。保留5.61%、5.07%和15条轨迹三个核心数字，移除摘要中的0.12720等次要细节；它们仍完整保留在结果、表图和讨论中。反转在事后精度控制中消失，以及有向网络上的损失仍保留，均写入摘要。

## 各章节调整

- 引言：从候选限制的质量与成本权衡切入，明确比较两个计算所得集合的困难；随后区分参照采样与候选资格截断的作用位置，再提出研究问题与三项贡献。
- 相关工作：仅重写末尾定位段，说明本文关注质量差值能支持什么判断；原文献归因与引用序列保持不变，没有宣称其他研究均未考虑这一问题。
- 结果：五个小标题改为围绕需要回答的问题或发现组织。结果段落、数据、效应方向、统计限定与图表数值没有改动。
- 讨论：说明默认预算扫描为什么不能独立归因于预算；解释参照一致性、独立传播量与计算节省如何共同支持判断。
- 结论：回到质量判断依赖哪些计算环节、配对研究能澄清什么，保留研究范围和有限参照的边界。
- 编辑说明及cover letter：同步使用同一问题、发现与价值表述，避免以实验批次数量为中心。

## 网络样本的说法

英文摘要采用“a small, selected sample of real-world networks”，中文为“规模有限、经选择的真实网络样本”。随后明确三张外部拓扑与四张小规模接触图单独分析。这里的“小”主要描述独立真实网络样本数量；四张接触图本身的节点规模也小。没有把千级外部网络统称为小图，也没有把路径、世界或条件数当作网络样本。次要合成图仍按两个固定实例报告。

## 术语约定

| 英文 | 中文 | 本版处理 |
|---|---|---|
| full-candidate reference | 全候选参照 | 不改称最优解或真实最优基准 |
| reference budget | 参照预算 | 指用于选择的采样世界预算 |
| ranking precision | 排名精度 | 区分求解容差和已检查的候选池稳定性 |
| independent spread evaluation | 独立传播评估 | 独立于选择世界，不等于独立网络实验 |
| incremental spread | 增量传播量 | 保持总传播量减种子数的定义 |
| small, selected network sample | 规模有限、经选择的网络样本 | 不暗示随机抽样或网络总体代表性 |

## 核验与边界

新增文本中的关键结果与现有precision CSV和arm_path.csv逐项核对。方法、实验设置、结果正文、作者信息及声明逐字保留；全部原始表格、图、参考文献、模板和继承的分析文件通过哈希比对。中英对应段落检查数字、数学表达、引用及图表交叉引用。英文正文16页，中文正文18页；两者分别编译两次并全部渲染。可视检查记录另存于qa/render_checks.json。

此前补充材料正文、PDF及资产原样保留，本轮不声称重新翻译或重新编译补充材料。中文全文翻译覆盖英文正文，图内英文标签及参考文献保留原样。本轮没有执行新的训练、种子搜索、传播模拟、实验runner、假设检验或全量分析再生成。
