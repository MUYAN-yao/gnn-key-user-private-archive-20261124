1 Evidence layers and protocol
The original 42-condition experiment remains an archived layer. Its post-hoc set and uncertainty diag-
nostics are identified as such. The new 520-condition protocol was frozen before its outcomes, after the
original findings and resource timings were known. It is a prospective extension using known datasets.
All conditions, random paths, source hashes and outcome files are retained. No outcome-based ex-
clusions were made. The five components contain 200 resolution, 60 seed-budget, 160 parameter, 80
coupling and 20 synthetic-scale conditions. Each has nine arm executions and 10,000 evaluation worlds.
Random-pool repetitions are averaged within path for primary statistical summaries. Selection IDs are
nested prefixes, and evaluation uses a separate family. The frozen protocol, configuration and source
manifests are included in the reproducibility package.
2 Implementation audit
All 42 archived hashes were checked. Thirty-two arm traces and 64,000 evaluation values were exactly
reproduced. The small-graph suite contains 108 edge-time uniform comparisons, 9,600 chain outcomes,
720 cyclic-graph outcomes, 720 fixed-edge reachability checks and 15 restricted-greedy comparisons.
An initial audit report mislabeled the 108 hash checks as 324; the original record is preserved with a
count erratum. This affects the label only, not the computations. For the chaina→b→cunder step
coupling,p=.5,h=2, world 5 and lexicographic endpoint codes,f({a}) =3 butf({a,b}) =2. The
first seed set activatesbone round later, changing the random key for its outgoing edge. This supplies
a concrete finite-world nonmonotonicity example. Fixed-edge coupling instead uses the step-zero edge
key in every round. Its spread is exactly the union of horizon-limited reachability sets.
3 Statistical interpretation
Paired Monte Carlo intervals use the sample standard deviation of the per-world difference divided by√
10000. The displayed normal-approximation intervals are conditional and pointwise. Across-path
intervals resample ten independent pseudorandom paths on each fixed real graph, or five on a fixed
synthetic graph, 10,000 times with analysis seed 20261015. These percentile intervals have limited
precision and are not simultaneous confidence regions. The primary family has 24 two-sided exact sign
tests: six candidate types against full on four real graphs atk=5,W=5120,p=.01,h=3, step coupling.
Exact zero path differences are omitted from the binomial sign count and reported; all-zero contrasts
receivep=1. Holm adjustment is applied to the entire family. This tests sign balance conditional on a
fixed network and algorithmic protocol, not mean equivalence. No significance tests are used to select
which sensitivity results to report.

8 Random pools, tolerances and timing
Three pool permutations are generated per network/path independently of the selection worlds and are
held fixed across budgets and propagation parameters. Their individual results remain available. Averag-
ing the three per-world evaluations before calculating a paired MC standard error preserves their shared
evaluation-world dependence. Averaging their path-level effects avoids treating the random repeats as
independent paths. The tolerance grid is 0, 1, 2.5, 5, 10 and 20 percent of full incremental spread. The
file tolerance_sensitivity.csv includes both the fraction meeting a point-estimate threshold and a more
conservative descriptive conditional-loss-bound readout. The latter divides a pointwise upper loss bound
by a point-estimate denominator; it is not a ratio confidence interval or a confirmatory noninferiority
test. Warm compiled selection and independent evaluation are timed separately. A full-pipeline attribu-
tion adds graph preparation, common world materialization and the relevant ranking cost. It does not
count every other ranking’s cost against a single method. Five additional randomized repetitions per real
graph and nine arms yield 180 observations; these repeats do not increase utility sample size. Initial
compilation, environment and peak working set are recorded separately.
9 Source-data map and reproduction
all_arm_metrics.csv retains all 4,680 arm rows. path_level_metrics.csv additionally expresses random
pools as within-path averages. group_summary.csv contains the complete setting-specific summaries;
reference_transitions.csv contains adjacent-budget reference diagnostics; primary_sign_tests_holm.csv
contains the complete primary family; timing_repeats.csv and tolerance_sensitivity.csv support their
named analyses. Every condition JSON has a companion compressed NumPy archive containing all
evaluation outcomes and round-level total scores. The local package contains the frozen engine and
runner, configuration and protocol hashes, independent analysis and plotting scripts, a minimal semantic
smoke test, data cards, the original preprocessing script, and command-line reproduction instructions.
Provider archives are obtained separately and checked against their recorded hashes. No public archival
DOI has yet been assigned. This document is for author review; administrative declarations must be
finalized before submission.
