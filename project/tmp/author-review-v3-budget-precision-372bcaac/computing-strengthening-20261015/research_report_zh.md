# Computing 修订结果与投稿判断

本轮已实际完成代码审计、冻结扩展协议、全部实验、统计分析及稿件构建。研究定位仍是候选限制的评价研究；没有添加 GNN，也没有将编译加速包装成新算法。原始数据、旧稿与原42条件结果保持独立。稿件可交作者最终审核，但资助、作者批准、公开复现安排等仍待处理。

扩展包含 **520 个条件、4,680 次实验臂执行、46,800,000 个保留的逐世界评估计数**；串行总耗时 32.7 分钟，峰值进程工作集 780 MiB。四张真实图各有10条路径，两张合成图各5条。这些数量不能当作独立网络样本量。

最重要的结果是：最高两档预算间虽有 16/40 个集合变化，平均收益仅增加 0.0111 个节点；加权4k的均值对比随预算从正转负，而非加权度、PageRank在最高预算分别复现 39/40、40/40 条完整有序轨迹。**应收窄“截断失败”的表述，转而解释预算与排序怎样改变成本和收益判断。**

固定边对照用于检查耦合敏感性，不能由两种实现的结果差异直接推断哪一种更符合真实传播。原按步耦合的三节点反例只否定其固定世界目标自动单调的说法；本轮保持逐轮全枚举，没有使用未经证明适用的CELF。

参数实验覆盖 p=.005/.01/.05 与 h=1/3/5 的预定子集，不是全部排列。更大种子预算仍不包含 SFHH k=20；原范围限制没有隐藏。两张较大图为合成实例，其加权/非加权度按构造相同。全部设置与结果见 Fig4、`group_summary.csv`、`network_metadata.json`；失败或不利结果均保留。

## 7. 可以支持的贡献与下一步优先方向
可支持的贡献是：在明确的有限模拟参照下，把轨迹/集合、独立传播效用、实际候选覆盖和分项计算成本一起评价；给出排序、参数和耦合的对照，以及可复核的输出与诊断脚本。创新点必须放在这些可量化证据与评价问题的交叉处，不能把“采样越多通常越稳定”本身称为新发现。

后续优先级：**第一，新增不同来源及较大真实网络的外部验证；第二，若要主张实际可用，确定有领域依据的损失容忍度并另做前瞻性验证；第三，在传播期限与质量目标一致的条件下比较高效IM基线。** GNN不是当前稿必须补上的模块；把它加入需要新的训练/验证/跨图评估设计，容易分散当前论文问题。
