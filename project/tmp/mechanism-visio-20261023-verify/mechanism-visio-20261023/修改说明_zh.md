# 本轮机制图与文字修改

新增两张图，均在 Microsoft Visio 中通过原生形状绘制，可逐项编辑。

1. 正文图1：计算评价机制总览。上层展示图、候选池、共享选择世界、全候选/受限贪心和独立评估；中层用 ca-GrQc 的真实候选成员变化说明精度如何影响截断和下游种子；下层把轨迹/集合一致性、独立传播效用和成本分开。
2. 补充材料图2：按步耦合的时序反例。用三节点链说明，多加一个初始种子会提前其尝试时点，从而改变所用随机数；在特定世界中可由传播3个节点变为2个节点。图注保留“不由此直接否定次模性或固定种子集边际传播规律”的边界。

写作上修改了引言末段，新增方法首节，更新图注与交叉引用。采用计算类顶会常见的“总体结构—关键变量—输入输出—形式化细节”顺序，避免把新图写成算法创新或新实验证据。主文从19页变为20页，补充材料仍为11页；期刊模板、字号、行距和版心不变。

风格参考来自 Nature 的 AlphaFold 图1e及 NeurIPS 的 Transformer 图1，借鉴信息流、模块层级、对齐和直接标注的原则，未复制其图像。具体来源及设计依据见 `audit/design_reference_and_evidence.md`。

当前 `.vsdx` 包含2页、111个原生形状，其中57个含可编辑文字；没有嵌入图片。Visio本机直接导出PDF失败，因此采用 Visio原生SVG导出后转矢量PDF的路线。SVG中的样式被显式化、Arial映射为Helvetica，并检查了箭头、字体和版面；PDF不含栅格图。原生Visio文件与导出PNG均保留。

本轮补的是计算过程及其作用路径的解释，不能替代真实传播因果机制实验。未新增效用实验，未改变效应量、统计单位、事后敏感性身份、原始矩阵或已有审计结果。
