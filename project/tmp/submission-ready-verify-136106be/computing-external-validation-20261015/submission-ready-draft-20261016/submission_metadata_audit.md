# Submission metadata audit

This audit records how confirmed submission metadata is represented in this local
submission-preparation package. It does not replace the corresponding author's
manual entry of the same information in the Springer submission system.

| Item | Evidence/provenance | Written location | Status |
| --- | --- | --- | --- |
| Author order and spelling | Project legacy manuscript; author confirmation in the current task | `manuscript/manuscript.tex`, `Online_Resource_1.tex`, cover letter | Consistent |
| Affiliations and corresponding email | Project legacy manuscript; author confirmation in the current task | Main manuscript title block; Online Resource title block; cover letter | Consistent |
| Author contributions | Project legacy manuscript; author confirmation in the current task | Main manuscript Statements and Declarations; Chinese checklist | Consistent |
| Approval to submit | Explicit author confirmation in the current task | Main manuscript; cover letter; Chinese checklist | Stated; online-system confirmation remains a manual action |
| Funding | Legacy statement: provincial undergraduate innovation and entrepreneurship training project; author confirmation in the current task | Main manuscript; cover letter; Chinese checklist | Consistent, unnumbered |
| Grant identifier | No identifier located in project materials | Not asserted | No value to enter unless the corresponding author supplies one in the journal system |
| Competing interests | Legacy declaration of no competing interests; author confirmation in the current task | Main manuscript; cover letter; Chinese checklist | Consistent |
| AI-use disclosure | Manuscript Methods record plus author confirmation in the current task | Main manuscript Statements and Declarations; Chinese checklist | Consistent |
| Third-party data access | `audit/journal-and-literature.md`, provider citations, source manifests | Main manuscript; Online Resource; README | Provider files not redistributed |
| Code, outputs and reproducibility materials | Local package contents and author-confirmed review-access strategy | Main manuscript; Online Resource; README | Submission package only; no public URL asserted |
| Public repository URL, DOI, ORCID, code licence | No verified value located | Not asserted | Leave blank unless the corresponding author has a real value to enter |

## Consistency rule

The author-facing statements are identical in scope across the manuscript,
supplement, cover letter, editor summary and Chinese checklist. Frozen experiment
outputs and protocols are not altered by this metadata integration. The remaining
actions are web-form entry and manual upload, not missing scientific evidence.
